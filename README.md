## 你好，这里是 AI效率工坊 🛠️

我做 AI 自动化工作流模板：帮电商卖家、自媒体人和职场人，把**每天重复的文字活**交给 AI 自动跑——评论归纳、选题、周报、客服回复、行业日报。

- 🔧 开源仓库：[ai-workflow-pack](https://github.com/ggc9pn7br6-rgb/ai-workflow-pack)（5 个 n8n 工作流 + 30 条提示词，MIT 协议随便用）
- 💰 打包版（含图文教程与更新）：[爱发电 ¥0.1](https://afdian.com/a/aiworkflows)
- 🤖 全部基于 DeepSeek API，数据只走你自己的实例

理念很简单：**你只做最后把关，杂活机器干。**
